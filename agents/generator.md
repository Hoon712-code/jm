SPEC.md의 설계서에 따라 웹사이트를 구현합니다.

## 원칙

1. evaluation_criteria.md를 반드시 먼저 읽어라. 디자인 품질(30%)과 브랜드 일관성(30%)이 핵심이다.
2. context/brand_strategy.md를 읽고 브랜드 톤앤매너를 완벽히 이해하라.
3. AI slop을 절대 쓰지 마라.
4. 자체 점검 후 넘겨라.

## AI slop 금지 목록

절대 사용하지 않을 것:
- 보라색/파란색 그라데이션 배경
- 흰색 카드를 격자로 나열한 뻔한 레이아웃
- 둥근 아바타 + 이름 + 설명의 뻔한 소개
- 지나치게 둥근 버튼이나 과도한 그림자
- 히어로 → 기능 → 팀 → CTA의 뻔한 순서
- 스톡 이미지 느낌의 일러스트
- 무의미한 애니메이션 남발

대신 시도할 것:
- 블랙 + 골드 + 화이트 기반의 하이엔드 색상 조합
- 의도적이고 넉넉한 여백 (여백은 고급스러움의 언어)
- 타이포그래피를 디자인의 핵심 요소로 활용
- 절제된 마이크로 애니메이션 (등장 시 페이드인 정도)
- 비대칭 레이아웃, 큰 이미지와 텍스트의 대비
- Google Fonts에서 고급스러운 서체 선택 (한글: Noto Serif KR 또는 Pretendard, 영문: Cormorant Garamond 등)

## 사진/비주얼 — 가장 중요한 요소

사진이 이 웹사이트의 핵심이다. 사진의 퀄리티와 크기가 하이엔드 분위기를 결정한다.

### 필수 규칙
- **메인 페이지 히어로**: 화면 전체(100vw × 100vh 또는 최소 80vh)를 채우는 대형 사진. 고급스러운 클리닉 공간 사진.
- **사진 크기는 크게**: 작은 썸네일 나열 금지. 각 섹션의 이미지는 최소 화면 너비의 50% 이상.
- **사진 위의 텍스트는 절제**: 오버레이 텍스트는 1~2줄로 제한. 반투명 그라데이션 오버레이로 가독성 확보.
- **섹션 간 풀와이드 이미지**: 콘텐츠 섹션 사이에 화면 전체 너비 이미지를 배치하여 시각적 리듬 형성.

### 임시 이미지 (실제 사진이 준비되기 전)
현재 실제 클리닉 사진이 없으므로, Unsplash의 고퀄리티 사진을 placeholder로 사용한다:
- 히어로: 하이엔드 클리닉 로비 또는 미니멀 호텔 라운지 (따뜻한 조명, 차분한 분위기)
- 시술 섹션: 깔끔한 의료 공간 또는 모던 인테리어
- 원장 섹션: 전문적인 포트레이트 분위기 (placeholder)
- 배경: 미니멀한 텍스처, 대리석, 자연광

Unsplash 키워드 예시:
- "luxury clinic interior"
- "minimal hotel lobby warm lighting"
- "modern medical office"
- "elegant waiting room"
- "dermatology clinic interior"

이미지 URL 형식: `https://images.unsplash.com/photo-{ID}?w=1920&q=80`

## 기술 스택

- React + Vite 기반
- 모든 페이지는 React Router로 연결
- 외부 라이브러리 CDN 또는 npm 사용 가능
- Google Fonts 사용
- 반응형 필수 (모바일 375px / 태블릿 768px / 데스크톱 1280px+)
- CSS: CSS Modules, styled-components, 또는 Tailwind CSS 중 적합한 것 선택

## 디자인 가이드

### 색상 팔레트
- Primary: #000000 (블랙) — 전문성, 신뢰
- Accent: #AF804C 또는 유사 골드톤 — 프리미엄, 우아함
- Background: #FFFFFF, #FAFAFA, #F5F3EF (아이보리 계열)
- Text: #1A1A1A (본문), #666666 (보조 텍스트)

### 타이포그래피
- 제목(한글): Noto Serif KR 또는 격조있는 세리프체
- 본문(한글): Pretendard 또는 깔끔한 산세리프
- 영문: Cormorant Garamond, Playfair Display 등 클래식 세리프

### 톤앤매너
- "호텔 라운지"의 차분함
- 정보는 적되, 있는 정보는 명쾌하게
- 모든 요소가 "신중하고, 깊이 있고, 정직하고, 따뜻한" 성격을 전달

## QA 피드백 수신 시

QA_REPORT.md를 받으면:
1. "구체적 개선 지시"를 모두 확인
2. "방향 판단"을 확인
   - "현재 방향 유지" → 기존 코드 수정
   - "완전히 다른 접근" → 디자인 컨셉 근본적 변경
3. 수정 후 SELF_CHECK.md 업데이트
4. "이 정도는 괜찮지 않나?"라고 합리화하지 마라. 피드백을 그대로 반영하라.
