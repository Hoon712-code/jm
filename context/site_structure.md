# JM김정민피부과 기존 웹사이트 구조 분석

기존 사이트(jmskin.co.kr)의 구조를 정리한 문서. Planner가 참고하여 리뉴얼 페이지 구성을 설계한다.

---

## 현재 메뉴 구조

1. **ABOUT JM** — 원장 소개, 학력, 학회 활동
2. **SPECIAL IN JM** — 웰에이징 프로그램, 맞춤 리프팅
3. **LASER** — 써마지, 울쎄라, 티타늄, 오푸스, 젠틀맥스프로, M22 + 기타 10종
4. **INJECTABLES** — 스컬트라, 레디어스, 보톡스, 쥬베룩, 리쥬란, 엑소좀, 필로르가
5. **MEDICAL SKIN CARE** — 4가지 스킨케어 + 7가지 전문 프로그램
6. **DISEASE** — 티눈, 화상, 대상포진, 무좀, 아토피, 탈모
7. **BOARD** — 프로모션, 온라인 상담 게시판

## 현재 디자인 톤
- 주색상: 블랙(#000), 포인트: 골드(#AF804C), 배경: 화이트
- jQuery 기반, Swiper.js 슬라이더
- 반응형이나 전반적으로 노후화
- 캐치프레이즈: "아름다움에 과학을 더하다"

## 현재 사이트의 문제점 (브랜드 전략 문서 기반)
- 홈페이지가 제대로 작동하지 않는 부분 존재
- 원장의 핵심 강점(카이스트, 전문의, 1인 진료)이 30초 안에 파악되지 않음
- 시술이 "메뉴판"처럼 나열 → 가격 비교를 유도하는 구조
- 하이엔드 브랜드에 걸맞지 않는 UI/UX
- 시그니처 프로그램의 차별점이 명확하게 드러나지 않음

## 리뉴얼 시 고려할 페이지 구성 (제안)

### 메인 (랜딩)
- 히어로: 브랜드 에센스 전달 (30초 안에 핵심 파악)
- 원장 소개 섹션
- 시그니처 프로그램 하이라이트
- 진료 안내 + 위치

### 원장 소개
- 프로필, 학력, 자격, 철학
- "왜 JM인가"

### 시술 안내
- 시그니처 프로그램 (올인원, 부스터, 커스텀 케어) — 스토리 중심
- 리프팅/탄력 (써마지, 울쎄라, 티타늄, 오푸스)
- 주사/필러 (스컬트라, 보톡스, 엑소좀 등)
- 스킨케어
- 피부질환 진료

### 진료 안내
- 진료 시간, 위치, 연락처
- 오시는 길 (지도)

### 예약/상담
- 카카오톡 연결
- 전화 예약 안내
